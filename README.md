# StartSmart — Startup Feasibility & Resource Planning Platform

## Quick Start

```bash
npm install
npm run dev
```

## Documentation

All project documentation is in the `ProjectInstructions/` folder:

- **[Frontend README](ProjectInstructions/FRONTEND_README.md)** — Complete frontend code documentation, all 20 features mapped, tech stack, project structure
- **[Backend Instructions](ProjectInstructions/BACKEND_INSTRUCTIONS.md)** — Full backend + AI implementation guide with database schemas, migration order, and priority plan

## Tech Stack

React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui · Framer Motion · Recharts · React Three Fiber

## Features

20 modules including Budget Input, Industry Selection, Feasibility Calculator, Expense Engine, Break-Even Analysis, Risk Assessment, SWOT Analysis, Influencer System, Raw Materials, Marketing Budget, Funding Sources, Roadmap Generator, Analytics, Business Plan Export, Admin Dashboard, and more.
